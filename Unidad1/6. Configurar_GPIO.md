1. **Paso 1:** Habilitar el clock del periférico PTA: para esto revisamos en el manual la sección 7.3.10, para encontrar el registro **RCC_AHB1ENR**

<aside>
⚠️

**¡ADVERTENCIA!**
Los periféricos no pueden funcionar si el *clock* no ha sido habilitado correctamente. Uno de los errores más comunes entre desarrolladores de software principiantes es una configuración incorrecta del *clock* del periférico que desean utilizar.

</aside>

### 7.3.10 RCC AHB1 peripheral clock enable register (RCC_AHB1ENR)

Address offset: 0x30
Reset value: 0x0010 0000
Access: no wait state, word, half-word and byte access.

![image.png](attachment:48d67fd7-c82c-4ba5-a7c8-73dcb9422a42:image.png)

El siguiente código habilita el *clock* del puerto A

```nasm
    .equ RCC_BASE, 0x40023800        /* Dirección base del RCC */
    .equ RCC_AHB1ENR_OFFSET, 0x30   /* Offset del registro RCC_AHB1ENR */

    LDR R0, =RCC_BASE               /* Cargar la dirección base del RCC en R0 */
    LDR R1, [R0, #RCC_AHB1ENR_OFFSET] /* Leer el registro RCC_AHB1ENR (habilitación de reloj AHB1) */
    ORR R1, R1, #0x01               /* Establecer el bit 0 para habilitar el reloj de GPIOA */
    STR R1, [R0, #RCC_AHB1ENR_OFFSET] /* Escribir el valor actualizado en RCC_AHB1ENR */
```

1. **Paso 2:** Configurar el puerto `PTA6` como salida

### 8.4.1 GPIO port mode register (GPIOx_MODER) (x = A..I/J/K)

Address offset: 0x00
Reset values:
• 0xA800 0000 for port A
• 0x0000 0280 for port B
• 0x0000 0000 for other ports

![image.png](attachment:b19507b1-4a82-49f4-882d-fb3debf651e9:image.png)

Bits 2y:2y+1 MODERy[1:0]: Port x configuration bits (y = 0..15)
These bits are written by software to configure the I/O direction mode.
00: Input (reset state)
**01: General purpose output mode**
10: Alternate function mode
11: Analog mode

```nasm
    .equ GPIOA_BASE, 0x40020000
    .equ GPIOA_MODER_OFFSET, 0x0     
    
    LDR R0, =GPIOA_BASE                /* Dirección base de GPIOA */
    LDR R1, [R0, #GPIOA_MODER_OFFSET]  /* Leer el valor actual del registro MODER */
    BIC R1, R1, #(0b11 << 12)           /* Limpiar los bits 12 y 13 (MODER6) */
    ORR R1, R1, #(0b01 << 12)           /* Establecer 01 en MODER6 para configurar pin 6 como salida */
    STR R1, [R0, #GPIOA_MODER_OFFSET]  /* Escribir el valor actualizado en MODER */
```

1. **Paso 3:** El siguiente paso consiste en configurar el pin de salida en configuración push-pull, pues su objetivo es controlar el encendido de un LED y, por lo tanto, se deben poder configurar tanto niveles bajos como altos. Para ello, debemos configurar el registro GPIOx_OTYPER, de la siguiente manera:

### 8.4.2 GPIO port output type register (GPIOx_OTYPER)

Address offset: 0x04
Reset value: 0x0000 0000

![image.png](attachment:c386251d-c0ff-494f-8951-7598ae74c8a7:image.png)

El siguiente código se encarga de realizar la configuración.

```nasm
    /* 3. Configurar el pin en modo push-pull (OTYPER) */
    .equ GPIOA_BASE, 0x40020000
    .equ GPIOx_OTYPER_OFFSET, 0x4  
    
    LDR R0, =GPIOA_BASE                 /* Dirección base del GPIOA */
    LDR R1, [R0, #GPIOx_OTYPER_OFFSET]  /* Leer el valor actual del registro OTYPER */
    MOV R2, #1                          /* Configurar el bit correspondiente */
    LSL R2, R2, #6                      /* Desplazar el bit 1 a la posición del pin 6 */
    BIC R1, R1, R2                      /* Limpiar el bit 6 para configurar como push-pull */
    STR R1, [R0, #GPIOx_OTYPER_OFFSET]  /* Escribir el valor actualizado en el registro OTYPER */
```

1. **Paso 4:** Ahora es necesario configurar la velocidad del puerto. Para ello debemos configurar el registro GPIOx_OSPEEDR.

### 8.4.3 GPIO port output speed register (GPIOx_OSPEEDR)

Address offset: 0x08
Reset values:
• 0x0C00 0000 for port A
• 0x0000 00C0 for port B
• 0x0000 0000 for other ports

![image.png](attachment:141ade53-8abc-44eb-afb3-e9f7edba2b52:image.png)

El siguiente código realiza la configuración:

```nasm
    /* 4. Configurar la velocidad del pin (OSPEEDR) */
    LDR R0, =GPIOA_BASE                 /* Dirección base del GPIOA */
    LDR R1, [R0, #GPIOx_OSPEEDR_OFFSET] /* Leer el valor actual del registro OSPEEDR */
    MOV R2, #0x3                        /* Configurar velocidad muy rápida (11) */
    LSL R2, R2, #12                     /* Desplazar a los bits 12 y 13 (pin 6) */
    BIC R1, R1, #(0x3 << 12)            /* Limpiar los bits 12 y 13 para el pin 6 */
    ORR R1, R1, R2                      /* Establecer alta velocidad (11) para el pin 6 */
    STR R1, [R0, #GPIOx_OSPEEDR_OFFSET] /* Escribir el valor actualizado en OSPEEDR */
```

1. **Paso 5:** Configuramos el puerto para que no tenga resistencia de Pull-Up ni de Pull-Down.

### 8.4.4 GPIO port pull-up/pull-down register (GPIOx_PUPDR)

Address offset: 0x0C
Reset values:
• 0x6400 0000 for port A
• 0x0000 0100 for port B
• 0x0000 0000 for other ports

# 🛠️ Ejercicio

## **Control de Frecuencia de Parpadeo con Listas y SysTick**

### **Descripción General**

El objetivo es programar en ensamblador (Assembly) para el microcontrolador **STM32F407** de forma que se cumplan las siguientes condiciones:

1. **Módulo SysTick**: Se empleará para generar interrupciones periódicas que controlarán el cambio en la frecuencia de parpadeo de, al menos, tres LEDs.
2. **Listas de Datos**: Se almacenará en memoria una lista con valores que representen diferentes frecuencias de parpadeo (por ejemplo, períodos en milisegundos).
3. **Tres LEDs**: Se utilizarán tres LEDs (podemos usar uno integrado en la placa y dos externos conectados a GPIO).
4. **Secuencia de Frecuencias**: El programa recorrerá la lista de frecuencias, aplicando cada valor para todos los LEDs, y luego pasará al siguiente valor de la lista.
5. **STM32F407VET6 Black Board**: Asegúrate de consultar la hoja de datos o documentación específica para conocer los pines GPIO disponibles y cómo configurar el SysTick.

---

### **Requerimientos de Hardware**

- **Tarjeta STM32F407VET6 Black Board**.
- **Tres LEDs**: Al menos uno puede ser el LED integrado. Otros dos se pueden conectar externamente a pines GPIO con resistencias limitadoras (*debes calcular el valor de la resistencia*).

---

### **Pasos Generales de Configuración**

1. **Configurar los pines GPIO** como salida para los tres LEDs.
2. **Configurar el reloj del microcontrolador** en esta tarjeta, por defecto, la frecuencia de reloj corresponde al HSI (High Speed Internal Oscillator), el cual correrá a una frecuencia de 16 MHz, en caso de que necesites otra frecuencia base, debes realizar una configuración diferente.
3. **Configurar el SysTick** para que genere interrupciones a un intervalo fijo (por ejemplo, cada 1 ms o 10 ms) con base en la frecuencia del sistema. Investiga cómo realizar la configuración de este módulo en un ARM Cortex M-4.
4. **Usar una Lista en Memoria** (sección `.data`) con valores que representen los diferentes períodos de parpadeo. Pueden ser valores explícitos o algún tipo de código para convertirlo al valor que necesitas.
5. **Bucle Principal** en el que:
    - Se recorra la lista de frecuencias.
    - Para cada frecuencia, se espere ese intervalo de parpadeo usando interrupciones del SysTick.
    - Se parpadeen los tres LEDs usando los mismos tiempos.
