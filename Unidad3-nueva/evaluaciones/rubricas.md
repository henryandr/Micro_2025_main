# Rúbricas de Evaluación - Unidad 3

## Rúbrica 1: Actividades Prácticas Semanales

| Criterio | Excelente (4) | Bueno (3) | Aceptable (2) | Insuficiente (0-1) |
|----------|---------------|-----------|---------------|-------------------|
| Funcionalidad | Funciona perfectamente | Funciona con errores menores | Funciona parcialmente | No funciona |
| Código | Limpio, modular, comentado | Funcional, algunos comentarios | Funcional básico | Desorganizado |
| Documentación | Completa y clara | Adecuada | Mínima | Ausente |
| Entrega | A tiempo, formato correcto | A tiempo | Tarde | Muy tarde/no entrega |

---

## Rúbrica 2: Proyecto Final

### Funcionalidad (25 puntos)

| Nivel | Puntos | Descripción |
|-------|--------|-------------|
| Sobresaliente | 23-25 | Todas las funciones + extras, manejo robusto de errores |
| Notable | 20-22 | Todas las funciones principales operativas |
| Aprobado | 15-19 | Funciones básicas operativas |
| Suspenso | 0-14 | No funciona o muy incompleto |

### Código (20 puntos)

**Estructura (8 pts)**:
- Drivers modulares: 3 pts
- Separación .h/.c: 3 pts
- Uso de constantes: 2 pts

**Calidad (7 pts)**:
- Sin duplicación: 2 pts
- Nombres descriptivos: 2 pts
- Manejo de errores: 3 pts

**Documentación (5 pts)**:
- Comentarios Doxygen: 3 pts
- Explicaciones: 2 pts

### Integración (10 puntos)

- Cada protocolo funcional: 2 pts × 4 = 8 pts
- Integración coherente: 2 pts

### Documentación (10 puntos)

- README: 3 pts
- Diagramas: 4 pts
- Instrucciones: 3 pts

### Presentación (5 puntos)

- Claridad: 2 pts
- Demo en vivo: 2 pts
- Q&A: 1 pt

**Total**: 70 puntos
